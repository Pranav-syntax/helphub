🫂 HelpHub: Community Emergency & Local Aid Platform
HelpHub is a hyper-local web application designed to connect individuals facing urgent needs (such as food supplies, emergency medical assistance, or transportation) with verified, trusted neighbors who can offer immediate help. The platform aims to reduce the feeling of isolation during crises and facilitate real, human-powered community support without the complexity of traditional bureaucracy.

✨ Features
Urgent Request Submission: Users can easily post requests categorized by need (e.g., Medical Assistance, Food Supplies, Transportation).

Hyper-Local Matching: Displays recent requests prioritized by proximity to the user, ensuring fast, relevant responses.

Verified Members: Integrates identity verification checks to build trust and accountability within the community.

Safety Focus: Safety features include in-app messaging and guidelines for safe public meetups.

Filtering: Users can filter requests by category and urgency.

Responsive UI: A clean, intuitive interface ensures easy use on web and mobile browsers.

🛠️ Technology Stack
HelpHub is built on a reliable and widely used technology stack:

Frontend: HTML5, CSS3, JavaScript

Backend Framework: Python Flask (for routing, handling requests, and server logic)

Database: MySQL (for persistent storage of user profiles and help requests)
